The rule

Two levels

Issue is a diagnosis. Solution is that same diagnosis plus a run that applies the fix. We turn either one into the task.

Level 01Issue

Issue

Diagnose the failure using the workspace and metrics.

InstructionWhat to diagnose and what the failure is.
WorkspaceCode, config, logs, and metrics from the recorded run.
EnvironmentContainer image, dependencies, model, and dataset.
Level 02Solution

Solution

Everything in Issue, plus repair instructions and rerun threshold.

IssueDiagnosis instruction, workspace, and environment.
SolutionFix instructions and threshold. Adds repair-and-rerun evaluation.

Submit

Two ways

Use an agent when the workspace already exists. Open a pull request for an idea, the materials, or a folder that is already built.

01

Agent

Paste this prompt. It follows package-task. Change the level to solution when a repaired run is included.

Package the workspace at <path> as an AutoRLBench issue task using https://github.com/Thinking-Space/AutoRLBench/tree/main/skills/package-task.
02

Pull request

Open it on Thinking-Space/AutoRLBench. We finish the task layout when the folder is not ready.

  1. 01
    Say which level

    Issue or solution, the domain, and the failure. An idea for the run is enough.

  2. 02
    Add only what you have

    Diagnosis instruction, workspace, and environment. Solution adds repair-and-rerun evaluation.

  3. 03
    Push the branch

    Use the commands below only when tasks/your-task-name is already built.

git clone https://github.com/Thinking-Space/AutoRLBench.git
cd AutoRLBench
git checkout -b contrib/your-task-name
git add tasks/your-task-name
git commit -m "Add your-task-name"
git push -u origin contrib/your-task-name
