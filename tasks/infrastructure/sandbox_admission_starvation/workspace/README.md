# Asynchronous agentic GRPO workspace

`python3 -B scripts/train_reproduction.py` launches the bundled Miles
fully-asynchronous trainer (Ray + Megatron + SGLang) on a single 8-GPU node:
4 GPUs train the policy (tensor-parallel 2, data-parallel 2) and 4 GPUs serve it as four SGLang engines. The policy is `Qwen/Qwen3.5-9B`, fetched by the prepare stage into `models/`.
`--print-command` prints the exact trainer command line without running it.

The workload is `data/public_repo_tasks.jsonl`, 512 synthetic Python
repositories with one planted defect each, regenerated by the prepare stage
with `scripts/build_public_tasks.py`. The policy debugs them with tools
(`list_files`, `read_file`, `search`, `run_tests`, `submit_fix`) over up
to eight turns and is rewarded for naming the defective file and function.
Each trajectory runs in its own sandbox. `runtime/sandbox_service.py` is the local sandbox control plane (create, upload, install, exec, delete over HTTP) that the launcher starts before training; `vendor/agent_runtime/` is the client-side runtime the rollout uses to reach it.

## Layout

| Path | Contents |
| --- | --- |
| `scripts/train_reproduction.py`, `scripts/run_config.json` | launcher and its topology / rollout / training configuration |
| `scripts/native_entrypoint.py`, `runtime/source/train_async_entrypoint.py` | local Ray bootstrap and the Miles async training driver |
| `runtime/rollout.py`, `runtime/fully_async.py` | rollout function: continuous producer, group collection, recycling |
| `runtime/agent_generate.py`, `runtime/environment.py`, `runtime/repo_tools.py` | multi-turn generate function, per-trajectory environment, tools and reward |
| `runtime/training_evidence.py` | before-train-step hook that records every optimizer update |
| `vendor/` | Miles, Miles plugins and Megatron (Core, Bridge) Python source |
| `logs/historical/` | sanitized console logs and derived metrics of the original 16-GPU runs |
| `logs/public_rerun/` | outputs of one run of this workspace on 8 × H800 (layout as below; host names and paths replaced) |
| `scripts/convert_hf_to_torch_dist.py` | one-time Hugging Face to Megatron checkpoint conversion run by the launcher |

## Outputs

Each launch writes `experiment_logs/<UTC time>-<pid>/`: `launch.json` (argv and
configuration), `train.log` (full console log), `rollout.<id>.json` (per-rollout
summary), `optimizer/step.<rollout>.<step>.rank<r>.json` (update identity, grad
norm, sampled parameter delta), `turns/*.jsonl` (one record per engine call and
tool batch), `env_setup/*.jsonl` (per-trajectory sandbox setup record) and `sandbox_service.log` / `sandbox_access.jsonl`.
