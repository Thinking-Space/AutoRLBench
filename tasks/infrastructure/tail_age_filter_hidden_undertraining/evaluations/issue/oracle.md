# Oracle：根因与证据（issue 级）

## 根因
异步 age 准入门控（rollout 落后超过 age_limit 个版本则丢弃）按 wall-time 过滤：
长任务 wall-time 长 → version-lag 大 → 被系统性过滤 → 模型很少练到长程行为。
聚合成功率被短任务主导（真实分布短任务占多数），掩盖了长程塌陷。

## 诊断陷阱
聚合成功率紧门控 0.954 vs 放宽 0.999（几乎一样），短任务成功率 1.000（正常）——
常规指标完全看不出问题。必须按 horizon 分层看。

## 证据（给分依据）
| 项 | 期望值 |
|---|---|
| 聚合成功率 tight vs relaxed | 0.954 vs 0.999（差异<0.1，看不出） |
| 短任务(h<=5)成功率 | ≈1.000（正常） |
| 长程(h>10)成功率 tight vs relaxed | 0.003 vs 0.869（塌陷暴露） |
| horizon 分布 | 短任务占多数（几何衰减），是聚合掩盖的前提 |

## 判分要点
- 根因必须落到**age 门控按 wall-time 过滤长任务 → 长程能力隐形欠训练**。
- 证据必须来自**按 horizon 分层的成功率对比**（长程段塌陷）。
- 只看聚合成功率得出"没问题" → Fail；未分层 → 证据不成立。
