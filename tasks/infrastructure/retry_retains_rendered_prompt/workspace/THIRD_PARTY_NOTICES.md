The Miles license is copied from the same recorded wheel's license file. The Core, Bridge and Energon license texts were retained from locally installed NVIDIA distribution license files (respectively versions 0.16.0rc0, 0.4.0rc0 and 7.3.2). They are reference license texts, not evidence that those installed Python versions are the vendored source versions. The recovered source package metadata and retained per-file notices identify the bundled components; the license-text origins are documented explicitly to avoid implying a different source provenance. Core's aggregate license includes notices for incorporated upstream components.

Per-file original and shipped SHA256 values, source identifiers and path replacement notes are in `../environment/runtime_sources.json`. Original local usernames/workspace paths were replaced in source comments and examples. Private generation/scoring implementation is omitted; publication changes and per-source identities are recorded in the environment inventories. Internal job identifiers, private project-path mappings, credentials and private payloads are not needed in this notice.

Public model assets are generated locally from the public `transformers.Qwen2ForCausalLM` architecture, with random initialization seed 20261115. No pretrained checkpoint or private task data is redistributed. Transformers, Tokenizers, PyTorch, Ray, SGLang, Transformer Engine, FlashAttention and other compiled/runtime dependencies are supplied by the environment rather than vendored as binaries here; their own distribution licenses apply. The public model architecture's implementation belongs to the installed Transformers distribution.

The default public workload uses one GPU for native Miles Ray/Megatron GRPO training and actual Hugging Face CPU inference (`--generation-backend hf-cpu`). Miles's `--debug-train-only` skips SGLang servers and actor-to-generator weight synchronization while retaining the configured native Ray actors, GRPO loss, forward/backward and optimizer updates. The CPU generation model stays at initialization. SGLang remains an environment dependency and an optional two-GPU generation backend; its presence in this inventory does not establish execution.

The optional SGLang attempt failed before training because its router did not become ready. That path remains unverified, and its configured weight-update interval of 100 would also leave generation weights unchanged between actor updates during the short probe. The default native failure/reference pair is validated; execution scope is recorded in the environment verification manifest. Historical selected-pod API logs and metrics are evidence from `historical_failure`, distinct from any newly generated smoke output.

The vendored Miles source is the generic package with unrelated, unverified optional extensions omitted. `../environment/privacy_exclusions.json` records the exact exclusions, source hashes before and after this pass, and static verification. The source inventory records the baseline; this exclusion manifest records the subsequent changes. The default native failure/reference validation uses the resulting source.
