# Diagnosis scope and root cause

The target defect is a same-token left-padding invariance failure in the actor scorer. When physical left padding changes while the real prompt tokens, response tokens, and valid token positions remain fixed, the actor's log-probabilities and PPO policy gradients change. This confirms unhealthy scoring behavior even though held-out accuracy alone does not show a decline.

Specifically, the TurboQuant adapter registers a custom attention function and sets its name in the model configuration, but omits the corresponding Transformers mask builder. In the recorded Transformers version, mask preprocessing returns `None` for an unknown custom attention name. Qwen2 passes that `None` mask to the custom attention wrapper, which forwards it to SDPA, allowing real-token queries to attend to preceding padding keys. The supplied cumulative-sum position IDs keep real-token positions aligned, but they do not prevent attention to padded keys.

In the visible workspace, `workspace/evidence/same_token_control.json` records the same-token comparison and its policy-gradient impact, `workspace/evidence/metrics.jsonl` records the original run including `hf_padding_logprob_effect_mae` at step 60, and `workspace/evidence/training_padding_observation.json` documents that all 512 recorded prompts in that round received left padding. A passing diagnosis may rely on the recorded same-token comparison, the scorer and registry call chain, or both; exact numeric values from unpublished author-only tests are not required.

The probability discrepancy between native rollouts and unpadded Hugging Face prefills is a separate, supported observation arising from differences between native prompt-prefill and HF fake-quantization paths. Credit an accurately supported diagnosis of that independent discrepancy as additional evidence, while keeping it distinct from the missing-mask explanation for the target same-HF left-padding comparison. A passing diagnosis does not need to claim that changing the mask alone explains or improves final held-out accuracy.

## Shared-image one-step reproduction

In the recorded shared-image reproduction, the faulty run executes one real optimizer update over 128 responses and uses the exact same 128 response token sequences as the healthy run. With the quantizer temporarily disabled, the same-token comparison yields mean absolute log-probability differences of 0.28739 for the faulty run and 0.00721 for the healthy run. In the observed fixed-width forward pass, the faulty attention wrapper and SDPA receive no mask, whereas the healthy forward pass receives a boolean mask excluding all 974 padding keys. Visible artifacts in `workspace/evidence/shared_image/` include the faulty metrics, original scalar log and three original rollout samples.
