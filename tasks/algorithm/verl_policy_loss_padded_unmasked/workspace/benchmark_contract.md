# Benchmark target contract

This benchmark asks whether the staged implementation recovers the standard veRL GRPO training target under the recorded model, data, budget and evaluation protocol. Custom policy code is treated as an attempted reimplementation of that reference, not as permission to redefine the benchmark target. A mathematically valid alternative objective can therefore be a deviation from this contract without being universally invalid.

Use code and recorded behavior together; a low reward or a custom function name alone is insufficient diagnosis. Do not infer that historical held-out accuracy must decrease in every case.

This is the benchmark's declared comparison target, added during packaging. It is not a claim about the original author's research intent.
