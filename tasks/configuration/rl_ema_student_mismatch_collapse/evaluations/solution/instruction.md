# Solution 指令（修复 + rerun 阈值）

在完成 issue 诊断（根因=EMA/student 评错权重 + 训练崩溃）的基础上：

## 修复
1. **评 EMA 权重**：用与训练一致的 EMA 权重评测，而非 student；
2. **修 nft_weight_scale**：不要把 mse 形式 [1.0, 0.2] 抄进 dpo 形式，确认能量对称 Δv=0⇒ΔE=0；
3. 处理退化组（全对/全错组占比过高 → 补采或丢弃）。

## Rerun 阈值
修复后应满足：
- 至少有一个 RL arm（EMA 评测）≥ SFT(0.44)；
- B1 训练曲线不再几步内归零自锁；
- 三组对比干净（评 EMA、训练不崩）。

## 产出
- 修复后的配置；
- rerun 的 EMA 评测结果 + 训练曲线；
- 修复前后对比。
