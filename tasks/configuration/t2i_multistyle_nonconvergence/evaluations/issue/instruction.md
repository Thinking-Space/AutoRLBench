# Issue 诊断指令（给被测 agent）

## 背景
一个多风格 T2I 风格化 SFT 训练（16 风格，全量约 14.5 万张）出现 loss 不收敛 / 收敛过慢、震荡。
同目录提供三个 run 的 loss 曲线与配置：全量+当前配置（待诊断）、全量+对照配置、小数据+当前配置。

## 你的任务
1. 阅读 `../training_report.txt` 与 `../metrics_summary.json`。
2. 用 `tools/inspect_logs.py` 检查 loss 曲线，阅读 `configs/` 下的配置。
3. **定位全量多风格 T2I 学不动 / 震荡的根因**，并给出支撑证据。
4. 输出诊断报告：根因、证据、以及（可选）修复方向。

## 规则
- 只依据本 workspace 提供的材料。
- 结论要可验证：给出你实际比较的指标或配置差异。
- 注意区分"相关"与"因果"：小数据能收敛不必然意味着数据质量是主因。
