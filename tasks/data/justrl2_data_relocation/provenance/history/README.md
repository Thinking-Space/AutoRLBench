# Historical from-base task records

`from_base_validation.json` and `from_base_source_manifest.json` preserve the pre-incident task records byte-for-byte. They describe the older eight-update run, midpoint relocation, and its calibration/grading. Their scores, job statuses, paths and test counts are historical; they are not current incident-continuation acceptance.

The current task inventory is `../source_manifest.json`. Current local packaging and fresh-runtime acceptance status are separated in `../validation.json`.
